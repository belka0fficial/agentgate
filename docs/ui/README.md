# UI Screenshot Inventory

`current/` is the canonical latest capture set for the transplanted dashboard.

- `current/desktop/` contains the 9 official desktop screens.
- `current/phone/` contains the 9 official phone-width screens.
- `current/overview/` contains stitched sheets for fast full-flow review.

`reports/` keeps milestone writeups from prior UI passes.

`archive/` preserves everything that is not part of the official current register:

- `archive/pre-cleanup-current-set/` is the last flat screenshot dump before this cleanup.
- `archive/pass1/`, `archive/pass1-register/`, `archive/token-amendment/`, and `archive/template-adoption/` keep earlier design iterations.
- `archive/transplant-checkpoints/` keeps the dashboard-next approval and palette checkpoint captures.
- `archive/chat-layout/`, `archive/chat-states/`, and `archive/fit-and-finish/` keep focused studies, QA captures, and layout explorations that are still useful historically but are not the main screen register.

If a screenshot is not one of the 9 desktop screens, 9 phone screens, or 2 stitched overview sheets, it belongs in `archive/` instead of `current/`.
