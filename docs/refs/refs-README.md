# UI Reference Folder — How To Read These

Extract the SHARED visual language across each category. Never reproduce any single image. These are taste targets; agentgate-ui-requirements.md + agentgate-ui-addendum-specimen.md are the law and win every conflict.

- `core-*` — rendering target for the Core (the specimen). Monochrome fine particles/lines on void black; iridescence appears only with activity. Filenames ending in a state name (idle-drift, listening-convergence, processing-turbulence, speaking-amplitude, thinking-fold, alert-fracture) map to the Core state machine: that image/clip is the visual character of THAT state.
- `annotation-*` — the documentation language: tiny uppercase mono micro-labels, hairline leader lines, registration marks, measurement arcs. Every annotation in the real UI must show a REAL value from the system.
- `base-*` — the register every screen lives in when nothing is happening: quiet, dense, precisely spaced dark dashboard. 90% of the product is this. The specimen layer sits on top of it in few deliberate places.
- Motion clips (`*.mp4`) — motion CHARACTER only. Triggers come exclusively from the motion law in the requirements doc: every animation is caused by a real system event; nothing loops decoratively. Idle = near-stillness, not an idle loop.
